# Change Log

## 0.1.0

Initial release.

- Chat panel over your indexed repositories, with clickable source citations
  that open the cited file at its line.
- Index workspace folder(s) or any GitHub repo into a local Aria server.
- "Recommend AI Team" panel — an open-source model roster per role.
- Start the local Aria server from inside VS Code.
- Configurable server URL (`aria.apiUrl`) — point at a local or remote Aria.
